My portfolio page

This is my personal portfolio website. I built it to show my game dev projects: Micronova, Ciros' Vengeance, and my Bachelor's thesis project.

What's inside
Index.html — the actual page. All the content, colors and layout are in there.
assets/ — the images and GIFs used on the page.
support.js, vendor/react*.js — code needed to make the page run. I didn't write this, it just comes with the tool I used to build the page.
